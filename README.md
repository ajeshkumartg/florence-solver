# Florence AI Solver 🤖✨

*Because reading questions is overrated.*

A slightly-too-powerful browser extension that strolls into Florence Academy quizzes like it owns the place… and then answers everything for you using fancy AI brains.

Supports multiple AI providers, because commitment issues are real.

---

## 🚀 Features (aka “Why this exists”)

* **Multi-Provider Support**
  Can’t decide? Neither can we. Pick from Groq, Gemini, OpenAI, or Mistral like it’s a buffet.

* **Automatic Detection**
  Sees radio buttons and checkboxes and goes: *“Ah yes, free marks.”*

* **Smart Answer Matching**
  Uses AI to pick answers that *look* correct (most of the time 👀).

* **Visual Feedback**
  Yellow = thinking
  Green = genius
  Red = “we don’t talk about that one”

* **Secure Storage**
  Your API keys stay in your browser. Not even we know what they are. (We’re not that nosy.)

* **Fast Processing**
  Faster than you pretending to read the question.

## 🛠️ Installation

### Option 1: From GitHub (a.k.a. DIY mode 🧑‍🔧)

1. Clone or download this repo
2. Go to `chrome://extensions/`
3. Turn on **Developer Mode** (yes, you’re a developer now)
4. Click **Load unpacked**
5. Select the `florence-solver` folder
6. Boom. You’re dangerous now.

## 📖 Usage (the fun part)

1. Install the extension
2. Click the extension icon
3. Pick your AI provider (like choosing your Pokémon)
4. Paste your API key
5. Hit **Save Key**
6. Open a quiz page
7. Click **🪄 Solve Page** and watch the magic happen

Now sit back and act surprised when everything gets answered.
